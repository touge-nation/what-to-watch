# What to Watch

A phone app (PWA) for rating movies and shows 0 to 100 by swiping, and getting picks that match your taste.

- **Training**: swipe right if you've seen it (then rate it), left if not interested, up to pin it.
- **For You**: only things you haven't seen, best match first.
- Toggle between **My services** and **Everything** (rent/buy included).

Data comes from [TMDB](https://www.themoviedb.org). Paste your own free TMDB key in Settings; it is stored only on your phone. Ratings live on the phone too, with a backup file in Settings.

No build step: it's plain HTML, CSS and JS, hosted on GitHub Pages.
